# フォトスリム

複数の写真をまとめて合計5MB以内に圧縮するブラウザアプリです。処理はすべてブラウザ内で行い、写真は外部に送信されません。

## 使い方

`index.html` をブラウザで開くだけで動きます（インターネット接続が必要です）。

## 仕様メモ

- 保存形式は JPEG / WebP を選べます
- 小さい写真は圧縮せず、空いた容量を大きい写真に回します
- HEIC（iPhone）は変換ライブラリで読み込みます
- フォント・ZIP・HEIC変換のライブラリはCDNから読み込むため、オフラインでは一部機能が使えません

## 正本について

このリポジトリが正本です。Claudeのアーティファクト版は閲覧用のコピーです。
